# Creator Labs assets in The Atlas

The Atlas remains the product. Creator Labs is identified only as the parent/publisher,
with the official unmodified white symbol in the header and a separate footer credit.
The compact dark workspace is adapted from Creator Labs `docs/brand/APP_ROLLOUT.md`,
`ACCENT_POLICY.md`, `VISUAL_SYSTEM.md`, `tokens/brand.tokens.json` and
`packages/ui/src/brand-layout.tsx` (canonical `/home/alex/work/projects/creators`).
Owner amendment: Atlas task t_683d62f7. No changes were made to Creators.

`sources.json` records byte-identical source paths and SHA-256 values. The symbol
is an owner-supplied Creator Labs brand asset, not Apache-2.0 project artwork or
a newly invented Atlas logo. No mirroring, clipping, recoloring or combined logo
lockup is applied. Branding/trademark rights remain with the owner.

Space Grotesk variable and IBM Plex Mono Regular/Medium are the selected local
font files from the canonical brand kit. Their original SIL Open Font License
texts are included unchanged as `SpaceGrotesk-OFL.txt` and `IBMPlexMono-OFL.txt`.
Upstreams: https://github.com/google/fonts/tree/main/ofl/spacegrotesk and
https://github.com/google/fonts/tree/main/ofl/ibmplexmono . Source distribution
provenance is also in the kit's `assets/fonts/SOURCES.json`.

No licensed React Bits Pro code or secrets are bundled. The existing functional
native HTML/SVG composition is retained; replacing it with a React framework or
an unrelated app shell would enlarge this bounded UI amendment. No new icons
were needed; the text-labelled graph controls retain their existing semantics.
Do not introduce another icon family: future icon additions use the established
Creator Labs Pixelarticons source and its license.

Routine controls, focus and graph chrome are neutral. Entity fill, hollow/dashed
literal nodes, dashed historical edges, labels and the full HTML relationship
list carry graph meaning without depending on decorative brand color. Signal
#FF003D is limited to a small footer slash artifact and the labelled error rule;
there are zero accent CTAs. Cut corners appear only on the neutral connection
button's visual backing, preserving its focus outline and rectangular hit target.
